## Embedded iOS Runtime Components

When packaged with `tools/package-ios.py`, the resulting `.ipa` bundles the
following open-source libraries built from `thirdparty/shiftglue-sdk`:

1. **ShiftGlue / ReXGlue** — BSD 3-Clause License (portions derived from Xenia).
2. **MoltenVK** — Apache License 2.0 (`VK_KHR_portability_subset` Vulkan-to-Metal translation layer).
3. **SDL3** — zlib License (`UIKit` windowing, Metal layer surface, touch controls, and Bluetooth game controllers).
4. **SPIRV-Cross & glslang** — Apache License 2.0 / BSD 3-Clause License (shader translation).
